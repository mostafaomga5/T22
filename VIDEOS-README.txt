1. هيكل المجلدات والتسمية الإجبارية (Folder Structure & Naming)
------------------------------------------------------------------------
يقرأ النظام الفيديوهات تلقائياً بناءً على المسار والاسم التاليين بدقة:

videos/
├── smm/                  # قسم إدارة حسابات السوشيال ميديا
│   ├── 1.mp4             # العرض الأول (إدارة سوشيال ميديا)
│   ├── 2.mp4             # العرض الثاني (إدارة سوشيال ميديا)
│   └── 3.mp4             # العرض الثالث (إدارة سوشيال ميديا)
│
├── web/                  # قسم تصميم وتطوير المواقع الإلكترونية
│   └── 1.mp4             # عرض إنشاء وتعديل المواقع (يفضل 16:9 أو 9:16)
│
├── ai/                   # قسم إنتاج الفيديوهات بالذكاء الاصطناعي
│   └── 1.mp4             # عرض فيديوهات الذكاء الاصطناعي (AI Reels)
│
├── ads/                  # قسم الحملات الإعلانية الممولة (Media Buying)
│   └── 1.mp4             # عرض نتائج وإبداعات الإعلانات الممولة
│
└── pages/                # قسم إدارة وتشغيل الصفحات والمنصات
    └── 1.mp4             # عرض إدارة الصفحات باحترافية

3. المواصفات الفنية القياسية (Technical Standards for Web & Mobile)
------------------------------------------------------------------------
لضمان تشغيل فوري بدون تقطيع على جميع الهواتف (iPhone / Android) والكمبيوتر:

• الصيغة والترميز (Format & Codec):
  - الامتداد: `.mp4` (حروف صغيرة دائماً).
  - ترميز الفيديو: `H.264 (AVC)` — (تجنب H.265/HEVC لضمان التوافق مع كل المتصفحات).
  - ترميز الصوت: `AAC` (أو بدون صوت للمعاينات الصامتة).

• المدة الزمنية (Duration):
  - 10 ثوانٍ كحد مثالي (من 8 إلى 15 ثانية كحد أقصى لسرعة التحميل).

• الأبعاد المدعومة (Supported Aspect Ratios):
  - عمودي (Reels / TikTok / Shorts): `1080x1920` بنسبة `9:16`.
  - أفقي (Websites / Desktop Showcase): `1920x1080` بنسبة `16:9`.
  - يتعرف الموقع تلقائياً على أبعاد الفيديو ويضبط الإطار ثلاثي الأبعاد.

• الحجم ومعدل البت (File Size & Bitrate):
  - الحجم المثالي للملف الواحد: أقل من `3 MB` إلى `5 MB`.
  - معدل الإطارات: `30 fps` أو `60 fps`.


4. أمر الضغط والتحويل السريع (FFmpeg One-Click Optimization)
------------------------------------------------------------------------
إذا كان لديك فيديو كبير الحجم وتريد تجهيزه للموقع في ثوانٍ بأعلى جودة وأقل حجم
مع قص أول 10 ثوانٍ وتفعيل التشغيل السريع (FastStart)، استخدم الأمر التالي:

ffmpeg -i input.mp4 -t 10 -vcodec libx264 -pix_fmt yuv420p -profile:v main -level 3.1 -crf 23 -preset slow -acodec aac -b:a 128k -movflags +faststart output.mp4


5. كيف يتعامل الموقع مع الفيديوهات تلقائياً؟ (Smart Auto-Detection)
------------------------------------------------------------------------
1. عند رفع الفيديو بالاسم الصحيح، يظهر زر التشغيل الذهبي ثلاثي الأبعاد فوراً.
2. إذا لم تقم برفع فيديو لقسم معين بعد، لن يظهر خطأ (Error 404) للمستخدم،
   بل يتحول الكارت تلقائياً إلى بطاقة ثلاثية الأبعاد تحمل شارة "قريباً / Coming Soon".
