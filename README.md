T2 | موقع الشركة
موقع تسويق رقمي متكامل بالعربي والإنجليزي، ومتجاوب مع الموبايل والكمبيوتر.
الملفات
index.html: الصفحة الرئيسية
style.css: التصميم والتجاوب
i18n.js: النصوص واللهجات (مصري، سعودي، خليجي، شامي، عربي فصيح، إنجليزي)
app.js: اختيار الدولة، تبديل اللغة، البورتفوليو، فورم واتساب، تأثيرات 3D
logo.png: شعار T2
تغيير الرقم
الرقم موجود في app.js في أول سطر:
const WA_NUMBER = "201090960743";
غيّره لو الرقم اتغير، بصيغة دولية بدون + ولا 00.
إضافة فيديوهات البورتفوليو
أنشئ المجلدات دي وضع فيها الفيديوهات (mp4، 10 ثواني):
videos/smm/1.mp4 ،2.mp4 ،3.mp4     إدارة السوشيال ميديا
videos/web/1.mp4 ،2.mp4 ،3.mp4     إنشاء وتعديل المواقع
videos/ai/1.mp4  ،2.mp4 ،3.mp4     فيديوهات الذكاء الاصطناعي
videos/ads/1.mp4 ،2.mp4 ،3.mp4     الإعلانات الممولة
videos/pages/1.mp4 ،2.mp4 ،3.mp4   إدارة الصفحات
أي فيديو مش موجود بيظهر "قريباً" تلقائياً.
